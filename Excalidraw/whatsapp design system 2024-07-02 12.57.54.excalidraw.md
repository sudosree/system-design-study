Scalability
- need multiple chat servers as a single chat server can't handle 1 B concurr connection
- with multiple CSs, users can connect to any chat servers
- how can we send message to the right chat server ?
- we can use Zookeeper, will keep track of the no. of registered CSs and which CS is responsible for which user
- Client A wants to send message to Client B
- Client A needs to know which is the right chat server for Client B
- Client A -> Load Balancer -> Zookeeper -> CS2
- Client A sends the message to CS2, CS2 checks the WS connection for Client B in it's hashmap and send
the message to Client B over that WS connection

pub/sub topic
- can be used to deliver messages to group
- client can send messages to any source server (responsible for sending messages to the pub/sub topic)
- source server sends the message to the pub/sub topic
- pub/sub topic is partitioned by group id, all the messages to a particular group will be present in one topic
- Chat servers are subscribed to the topic and gets all the messages and sent it to all the clients connected with them
over WS connection for that group id
