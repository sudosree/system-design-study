Batch Processing Approach
- we have huge no. of view data 100 B per day i.e. 100k per sec coming into our system
- as write vol is very high we should use Cassandra to store the write events as it is optimized for writes
- once data is written to DB, need to process and aggregate it based on diff time windows and calculate the top k videos
- Data agg svc does the aggregation and calculation and stores the result in database

How aggregation is done ?
- Apache spark is used for batch processing, distributed computing engine, optimized for handling large vol of data
- uses map reduce framework to aggregate the videos by view count in a window time and calacuate the top k videos
- map nodes read the events and compute key value pair mapping based on video id and calculate it's view count for every time window
- aggregate nodes aggregate the events and create a heap of size k
- reduce nodes aggregate the result from the agg nodes and return the top k videos 
- Top K videos are stored in the database
